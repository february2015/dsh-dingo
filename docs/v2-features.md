# dsh-dingo 2.5 功能说明

> 当前实现以本文件为准；旧版事件驱动卡片需求已归档/清理。2.x 期间的大改（1:1 卡片、草稿全量、面板交互、手机浮层）都在这份文件里。

## 核心变化

- 2.0 改为**会话 1:1 常驻卡片**：每个活跃对话一张卡片，状态变化更新同一张卡片。
- 卡片入口（统计胶囊 + 悬浮详细面板）放在 DSH 标准槽位 `sidebar.footer.action`（**左侧边栏**底部、设置按钮与底部功能按钮上方）：
  - 全局会话统计，hero 空白首页同样可见（root scope）；
  - **展开态胶囊为独立全宽条**：作为 footer 区最上一行，位于底部功能按钮（Cordis 面板图标等）与设置按钮之上；挂载时把所在的 footer 操作行设为可换行，胶囊独占一行（右侧显示会话总数），其它条目自动换到下一行；DOM 动态定位，不依赖核心类名；
  - 侧边栏收起为 56px rail 时压成紧凑小图标（owner `wide=false`）；
  - 面板向上弹出（侧边栏列 overflow:hidden，向下会被裁）。
- 会话头部操作行（`conversation.session.header.actions`）保留：
  - 当前工作区名称标签
  - `Rename` 按钮（自动命名）

## 状态与优先级

| 优先级 | 状态 | 含义 | 颜色/视觉 |
|---|---|---|---|
| 1 | 异常 | 任务失败 / 异常结束 | 红 |
| 2 | 疑问 | 需要你回答（审批 / ask_user / questions / 回复含疑问） | 橙 |
| 3 | 待阅读 | 对话已完成且需要你阅读（有答案） | 绿 |
| 4 | 草稿 | **任意**会话（非当前）输入框里有未发送内容 | 紫 |
| 5 | 等待后台/子任务/蜂群 | 主对话已完成，但后台任务/子对话/蜂群仍在跑 | 青/teal |
| 6 | 中间输出 | 正在执行且已经产生部分内容 | 浅蓝/cyan |
| 7 | 执行中 | 正在执行，尚无中间输出 | 蓝色 spinner |
| 8 | 正常 | 已完成且已看过 | 灰 |

> 当前对话正在输入内容属于正常状态，不触发顶部草稿提醒；但切到其它对话后，原对话的草稿会恢复为紫色提醒。
>
> 当前对话的「执行中 / 中间输出」**照实计入**统计（"在跑"是事实，不是提醒）；其余提醒类状态
> （异常 / 疑问 / 草稿 / 待阅读 / 等待）对当前对话不生效。
>
> 草稿数据来自宿主自己的持久化 `localStorage['dsh.conversation.<sessionId>']`，因此不依赖"本标签页
> 打开过"，跨标签页可见、刷新仍在；草稿卡还会显示草稿正文，可以直接当待办清单用。

## 卡片交互

- **统计胶囊**：默认只显示一个紧凑统计，包含：
  - 优先级闪烁点（异常红 / 疑问橙 / 草稿紫 / 待阅读绿）
  - 数量
  - 执行中 spinner + 数量
  - 中间输出 / 等待后台 / 正常等计数点
- **悬浮面板**：
  - 鼠标进入统计胶囊**立即**展开（无延迟）；点击胶囊可手动开关。
  - 关闭节奏（未锁定时）：点面板外立刻收 / 鼠标移开 2s / 完全空闲 5s；点卡片跳转后收。
  - 面板右上角有**图钉锁定**：空心灰=未锁定、实心橙=已锁定；锁定后不自动收起，方便连着切会话。
  - 面板向"离屏幕中心反方向"展开；手机浮层上还会按药丸落点做像素级夹取（见下）。
- **详细卡片**：
  - 第一行：工作区名（如有未完成后台任务，显示小 spinner + 数量）
  - 第二行：对话名
  - 不同状态不同颜色/图标
  - 支持 × 关闭（仅移除本次卡片）
- 会话销毁/删除后对应卡片自动移除。
- 正常卡片完成超过 1 小时后自动从卡片清单隐藏；如有草稿或后台任务会重新出现。
- 子代理 / Worker 会话不进入卡片清单。
- 卡片信息（标题/工作区）优先用客户端 store，其次用宿主 `/dingo.sessions` 返回的会话清单补齐——
  窄屏浮层拿不到 `useSessions`，全靠后者，所以手机上也能显示纯草稿会话及其标题。

## 手机浮层

- 视口 ≤ 900px 时，胶囊从侧栏 footer 切成视口上的固定浮层（插件自建 ReactDOM 容器，不依赖槽位）。
- **可拖拽**：按住拖到任意位置，松手落位；位置存 `localStorage['dsh-dingo.pill-pos']`，刷新后仍在
  （DSH 每次启动端口变化 = 换 origin，重启后回默认位）。
- **默认位置**：右侧、与对话头部 view tab 行同高（`PILL_DEFAULT_TOP`）。
- **面板几何**：按药丸落点把面板夹进屏幕——水平夹左右边缘，下方空间不够则向上弹并把高度限制在该侧
  可用空间内（`computePanelGeometry`）。
- **全屏按钮**：药丸最右端的四角图标，切换全屏/退出（Fullscreen API，`fullscreenchange` 同步状态）；
  浏览器不支持元素全屏（iPhone Safari）时自动隐藏。
- 药丸上不显示「N 个活跃会话」文字，只保留状态点与计数（省宽度）。

## 自动命名

- **按钮（Rename）**：独立调用 DeepSeek V4 Flash 生成标题。
- 会话读写走 `src/session-api.ts` 适配层：0.2 的 `sessionController.rename` / `events` 优先，
  旧 `apiProxy.sessions` 兜底，宿主调用统一 15s 超时。
- **对话内自然语言**：主 LLM 在当前上下文生成标题后调用 `rename_current_session` 工具改名（吃当前对话缓存）。
- `/dingo rename`：兜底命令，走独立 Flash 逻辑。
- 生成规则：
  - 只取最近 5 条用户消息；
  - 中文 6~20 字 / 英文 3~12 词；
  - 标题开头要有区分度，避免“帮我/优化/请问”等雷同前缀；
  - 只输出标题本身。

## 兼容保留

- 声音提醒（当前对话当/当当，其他对话叮/叮叮）
- 系统级通知（macOS / Windows）
- 深链直达
- 声音层去重 / DND / 静音时段（静音时段结束会按 end 时间定闹钟自动补播）
- `/dingo.sessions`：宿主把 `sessionController.list()` 转成紧凑清单（5s 缓存、上限 200 条）给客户端

## 开发与部署

```bash
npm run verify
```
