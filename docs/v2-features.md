# dsh-dingo 2.0 功能说明

> 当前实现以本文件为准；旧版事件驱动卡片需求已归档/清理。

## 核心变化

- 2.0 改为**会话 1:1 常驻卡片**：每个活跃对话一张卡片，状态变化更新同一张卡片。
- 卡片入口放在 DSH 标准槽位 `conversation.session.header.actions`：
  - `Rename` 按钮（自动命名）
  - 卡片统计胶囊 + 悬浮详细面板

## 状态与优先级

| 优先级 | 状态 | 含义 | 颜色/视觉 |
|---|---|---|---|
| 1 | 异常 | 任务失败 / 异常结束 | 红 |
| 2 | 疑问 | 需要你回答（审批 / ask_user / questions / 回复含疑问） | 橙 |
| 3 | 草稿 | 某个非当前对话有未发送输入内容 | 紫 |
| 4 | 待阅读 | 对话已完成且需要你阅读（有答案） | 绿 |
| 5 | 等待后台/子任务 | 主对话已完成，但后台任务或子对话仍在跑 | 青/teal |
| 6 | 中间输出 | 正在执行且已经产生部分内容 | 浅蓝/cyan |
| 7 | 执行中 | 正在执行，尚无中间输出 | 蓝色 spinner |
| 8 | 正常 | 已完成且已看过 | 灰 |

> 当前对话正在输入内容属于正常状态，不触发顶部草稿提醒；但切到其它对话后，原对话的草稿会恢复为紫色提醒。

## 卡片交互

- **统计胶囊**：默认只显示一个紧凑统计，包含：
  - 优先级闪烁点（异常红 / 疑问橙 / 草稿紫 / 待阅读绿）
  - 数量
  - 执行中 spinner + 数量
  - 中间输出 / 等待后台 / 正常等计数点
- **悬浮面板**：鼠标悬停或点击统计胶囊后展开，5 秒无操作自动关闭；点击卡片直达对话。
- **详细卡片**：
  - 第一行：工作区名
  - 第二行：对话名
  - 不同状态不同颜色/图标
  - 支持 × 关闭（仅移除本次卡片）
- 会话销毁/删除后对应卡片自动移除。
- 正常卡片完成超过 10 分钟后自动从卡片清单隐藏；如有草稿或后台任务会重新出现。

## 自动命名

- **按钮（Rename）**：独立调用 DeepSeek V4 Flash 生成标题。
- **对话内自然语言**：主 LLM 在当前上下文生成标题后调用 `rename_current_session` 工具改名（吃当前对话缓存）。
- `/dingo rename`：兜底命令，走独立 Flash 逻辑。
- 生成规则：
  - 只取最近 5 条用户消息；
  - 中文 6~20 字 / 英文 3~12 词；
  - 标题开头要有区分度，避免“帮我/优化/请问”等雷同前缀；
  - 只输出标题本身。

## 兼容保留

- 声音提醒（当前对话当/当当，其他对话叮/叮叮）
- 系统级通知（macOS / Windows）
- 深链直达
- 声音层去重 / DND / 静音时段

## 开发与部署

```bash
npm run verify
```

DSH profile 通过 `link:/path/to/dsh-dingo` 指向本仓库时，重启 DSH 后生效。
